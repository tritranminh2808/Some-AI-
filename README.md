# AI & Machine Learning Practice

This repository contains my source code, experiments, and solution notebooks for AI and Machine Learning problems, including training materials from national and international AI Olympiads.

# Contents
Personal AI Projects & Notebooks:** Machine learning models, data analysis, and baseline implementations using Python (PyTorch, Scikit-learn, Pandas).
VOAI & IOAI Olympiad Problems:** Solutions and algorithmic approaches for problems from the **Vietnam Olympiad in AI (VOAI)** and **International Olympiad in AI (IOAI)** selection rounds.
